# 👨‍🍳 Chef IA

O **Chef IA** é uma aplicação web inteligente que utiliza Inteligência Artificial para sugerir receitas criativas com base nos ingredientes que você já tem disponíveis na sua geladeira ou despensa. Desenvolvido para tornar a vida na cozinha mais prática e reduzir o desperdício de alimentos.

## 🚀 Tecnologias Utilizadas

* **HTML5 & CSS3**: Estruturação e estilização moderna com design responsivo.
* **JavaScript (Vanilla)**: Lógica da aplicação e manipulação do DOM.
* **Groq API**: Integração com modelos de IA de alta performance para gerar as receitas em tempo real.

## ✨ Funcionalidades

* **Entrada Inteligente**: Campo de texto simples para listar os ingredientes disponíveis.
* **Geração Instantânea**: Clique no botão "Gerar Receita Mágica" para receber instruções de preparo personalizadas.
* **Utilidade**: Funções de "Limpar" para começar novas buscas e "Copiar" para salvar sua receita favorita facilmente.
* **Design Dark Mode**: Interface elegante, focada na experiência do usuário.

## 💡 Como usar

1. Digite os ingredientes que você tem em casa no campo de texto (ex: "arroz, filé de frango, ovo").
2. Pressione o botão **"GERAR RECEITA MÁGICA"**.
3. Aguarde alguns segundos enquanto a IA cria a receita perfeita para você!
4. Use o botão **"COPIAR"** para levar a receita para o seu bloco de notas ou compartilhar com amigos.
